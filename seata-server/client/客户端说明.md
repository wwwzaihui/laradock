### Seata 客户端说明

#### 1. 客户端加载链路（优先级与顺序）
- 应用启动首先读取本地 `bootstrap.yml`，通过 Nacos 加载共享配置（shared-configs）。
- nacos配置data_id, key="service.vgroupMapping.my_tx_group",value==default" (必须)
- seataClient.properties的内容按照需要在nacos中配置,data_id= seataClient.properties中内容项


> 说明：`namespace` 使用 `${spring.profiles.active}`，示例为 `testing`。

---

#### 2. Nacos 配置项约定
- Namespace：`testing`
- Group：`SEATA_GROUP`
- Data ID：`按照需要使用
- 
发布到 Nacos 的 `seataClient.properties` 来自本地文件 `seata-server/client/resources/seataClient.properties`，当前关键项如下（完整内容以文件为准）：

```properties
# 事务分组映射到服务端集群
service.vgroupMapping.my_tx_group=default
# Seata-Server 在容器网络内的访问地址（docker-compose 服务名）
service.default.grouplist=seata:8091

# 传输与基础配置（节选）
transport.serialization=seata
transport.server=NIO
transport.type=TCP
```

公共配置 `config-common.properties` 的关键项：

```properties
spring.cloud.alibaba.seata.tx-service-group=my_tx_group
```

---

#### 3. 依赖收敛结论（重要）
- 不建议同时引入 `io.seata:seata-all` 与 `io.seata:seata-spring-boot-starter`。
- 建议：仅保留 `io.seata:seata-spring-boot-starter:${seataSpringBootStarterVersion}`（与服务端/脚手架版本匹配）。
- 若暂时无法移除 `seata-all`，需确保与 starter 版本完全一致，但长期建议移除。

推荐依赖清单：

```text
# declare  versions
springBootVersion=2.1.6.RELEASE
springCloudVersion=Greenwich.SR2
nacosClientVersion=2.0.0
springCloudNacosVersion=2.1.4.RELEASE
seataSpringBootStarterVersion=1.4.2

# declare libs dependency
"org.springframework.boot:spring-boot-dependencies:${springBootVersion}"
"org.springframework.cloud:spring-cloud-dependencies:${springCloudVersion}"
"com.alibaba.cloud:spring-cloud-starter-alibaba-nacos-config:${springCloudNacosVersion}"
"io.seata:seata-spring-boot-starter:${seataSpringBootStarterVersion}"
```

---

#### 4. 客户端与服务端对齐要点
- 事务分组：客户端 `tx-service-group=my_tx_group` 必须存在；
- 分组映射：`service.vgroupMapping.my_tx_group=default` 指向服务端集群名 `default`；
- 服务地址：`service.default.grouplist=seata:8091`（客户端与 Seata-Server 位于同一 docker 网络时这样配置）。

---

#### 5. 操作步骤（快速执行）


1) 将本地 `seata-server/client/resources/seataClient.properties` 发布到 Nacos：
   - Namespace：`testing`
   - Group：`SEATA_GROUP`
   - Data ID：`seataClient.properties`
   - 内容：使用本地文件的最新内容（已含 `seata:8091`）。
2) 确认本地 `bootstrap.yml` 的 `shared-configs` 顺序为：`config-common.properties` -> `seataClient.properties`，且 `group` 均为 `SEATA_GROUP`。
3) 重启或触发 Nacos 动态刷新，验证客户端日志中 Seata 初始化成功。
